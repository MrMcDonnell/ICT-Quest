Ch 1Types of Digital Devices
▾
Key Devices
MainframeLarge powerful computer that carries out complex tasks rapidly and can be used by many people simultaneously
SIM CardSubscriber Identity Module - identifies the device on the mobile phone network
SmartphoneMobile phone with Wi-Fi, internet access, complex OS. Uses more energy so requires more frequent charging
ConvergenceWhen the designs of devices change so they become similar to another (e.g. laptops that flip into tablets)
GPSGlobal Positioning System - uses satellite signals to pinpoint location. Does NOT need internet
GISGeographical Information System - renders maps, roads, houses. DOES need internet
User Interfaces
CLICommand Line Interface - typed commands, complicated and inefficient
GUIGraphical User Interface - windows, icons, menus. Very effective but requires high storage
Menu-DrivenChoosing from a list menu (e.g. ATMs). May not give user exactly what they want
Voice-DrivenBy speaking e.g. Siri
GestureSwipes/finger movements. Suitable for people with low mobility
Ch 1Input & Output Peripherals
▾
Input Devices - Key ones to know
OCROptical Character Recognition - scans text and numbers
OMROptical Mark Recognition - scans marks e.g. MCQ exam papers
QR CodeMatrix barcode - holds more data than linear, scanned at any angle
BiometricIris (most secure), Fingerprint, Face, Voice. Advantage: harder to trick. Disadvantage: stores personal data, expensive
Magnetic StripLeast secure card type - no PIN required
NFC / RFIDWireless payment (Apple Pay). When scanned, ID is linked to database records
Output Devices - Printers
TypeSpeedCost per copyQuality
Dot MatrixSlowestCheapestLowest. Can carbon print
InkjetQuickExpensiveHigh
LaserFastestMediumHighest
Ch 1Storage
▾
Storage medium = what holds the data (e.g. DVD disc). Storage device = what reads it (e.g. DVD drive)
Optical Media
MediaCapacityLaser
CD700 MBStandard wavelength
DVD4.5 GB (1-sided) / 18 GB (2-sided)Shorter red laser
Blu-Ray25 GB (1-sided) / 50 GB (2-sided)Shortest violet laser + scratch protection
How storage media represent binary
Hard DiskChanges magnetic charge on platter to positive/negative. Reading = magnetic→electric. Writing = electric→magnetic. Seek time = time for RW head to locate correct area
OpticalTiny bumps on surface. Laser shines on surface. Reflected light = 1, scattered light = 0
FlashDifferent levels of charge in individual cells. No moving parts = portable + energy efficient
Data Calculations
8 bits = 1 byte | 1 KiB = 1024 bytes | 1 GiB = 1024³ bytes
To find bits in X GiB: X × 8 × 1024³

Ch 3Memory & Processors
▾
RAMVolatile - data lost when power lost. Stores programs currently in use. Bigger RAM = better performance
Virtual MemoryCreated when RAM is full. Secondary storage used instead. Much slower performance
ROMNon-volatile - data kept when power lost. Stores boot data. Cannot normally be changed
EPROMErasable with UV light
EEPROMErasable with high voltage electricity. Developed into flash memory
Flash MemoryType of EEPROM. No moving parts. Portable and low power
Clock SpeedNumber of instructions per second a processor can carry out. Measured in Hertz (Hz)
Ch 1Selecting ICT Systems for Specified Needs
▾
The exam often asks you to select and justify suitable hardware or software for a given scenario. You must consider the specific needs of the user, including any accessibility requirements.
How to approach these questions
Identify the needWhat is the person trying to do? What are their limitations or requirements?
Select a device/softwareChoose something appropriate and name it specifically (e.g. "a tablet" not just "a device")
Justify your choiceExplain WHY it meets the need - link back to the features of that device
Common scenarios and suitable choices
Scenario / NeedSuitable device/softwareWhy
User with visual impairmentBraille keyboard, screen reader software, voice-driven interfaceAllows input/output without relying on sight
User with low mobilityGesture interface, eye-tracking, voice inputRemoves need for physical keyboard/mouse
Working on the move / travellingLaptop or tablet, mobile broadbandPortable, battery-powered, wireless internet access
Presenting to a large groupData projector, presentation softwareProjects large image for audience; software allows slides/animations
Storing large amounts of data cheaplyHDD or magnetic tapeHigh capacity at low cost per GB
Fast portable storageSSD or flash driveNo moving parts, fast access, portable
Scanning exam mark sheetsOMR scannerReads marks quickly and accurately
Security access controlBiometric scanner (iris most secure)Unique to individual, harder to fake than a PIN
Accessibility features in software
Screen readersRead on-screen text aloud for visually impaired users
Font size / zoomEnlarges text and interface elements
High contrast modeMakes text easier to read for users with visual impairments
Sticky keys / filter keysHelps users who cannot press multiple keys simultaneously
Voice recognitionAllows users to control software and dictate text using their voice
Ch 4Digital Communications
▾
BandwidthAmount of data transferred per second. Higher = faster uploads/downloads
LatencyTime it takes data to travel between two devices. Lower = less lag
BufferArea of temporary storage used when streaming. If buffer empties, video pauses
TetheringHost device shares its mobile broadband with another device. Reduces bandwidth for both
Network Types
LANLocal Area Network - small geographical area e.g. school
WANWide Area Network - larger area. Internet is the largest WAN. Slower than LAN
PANPersonal Area Network - devices near one individual. WPAN = wireless version
Wired vs Wireless
Wired advantagesWireless advantages
FasterLower cost (no cables)
More stableLess maintenance
More portable, less mess
Wi-Fi vs Bluetooth - when to use each
Wi-FiBluetooth
RangeUp to ~100mUp to ~10m
SpeedMuch fasterSlower
Power useHigherLower
Best forConnecting to the internet, streaming, large file transfersConnecting nearby personal devices (headphones, keyboard, phone to speaker)
ExampleLaptop connecting to home routerPhone connecting to wireless earbuds
Wi-Fi = internet access and fast data transfer over longer distances.
Bluetooth = short-range device-to-device connection without internet.
Broadband, Mobile Broadband and Cellular Networks
BroadbandHigh-speed internet connection via a fixed line (e.g. fibre optic or cable) to a home or building. Used with a router to create a Wi-Fi or wired network
Mobile BroadbandInternet access using a mobile data connection (3G/4G/5G) via a SIM card. Used in smartphones or portable devices. Not fixed to a location
Cellular NetworkThe network of mobile phone masts that provides 3G, 4G and 5G coverage. Devices need a SIM card to connect. Tethering shares this connection with other devices
Ch 5Networks
▾
IP vs MAC Addresses
IP AddressNOT fixed - changes with network. Assigned by DHCP. IPv4 = 8 numbers with dots. IPv6 = 8 groups of 4 hex characters with colons (developed because devices outnumbered IPv4 addresses)
MAC AddressFixed - unique to device. 6 pairs. First 3 = manufacturer. Last 3 = specific device/NIC
Network Components
RouterStores all IP addresses. Forwards traffic on fastest route
SwitchHas many ports for wired device connections
GatewayConnects LANs to WANs. Firewalls are found here
WAPWireless Access Point - connects Wi-Fi devices to a wired network
BoosterAmplifies network signal to cover larger distances
Network Types
Peer-to-peerDevices share resources directly - no server
Client-serverAll devices connect to a central server. Benefits: roaming profiles, centralised backup, shared peripherals, admin control
Encryption Types (weakest → strongest)
Caesar CipherShifts all characters by a fixed number. Very easy to crack
WEPAll network data encrypted with same key. Easy for eavesdroppers to crack
Symmetric KeySame key used to encrypt and decrypt. Both parties must share the key
Public KeyTwo keys - public key encrypts, private key decrypts. Most secure
WPAUpdated WEP. Every device and every data packet gets a unique key
Other Security Measures
FirewallFound at gateways. Controls what can enter/leave the LAN
VPNVirtual Private Network - encrypted tunnel for secure remote access to a LAN
Filter SoftwareBlocks/allows websites by URL using whitelist (allowed) or blacklist (denied)
Ch 6Risks to Data
▾
Malware Types
VirusAttached to emails. Spreads between files
RansomwareEncrypts files and demands a ransom to restore them
SpywareMonitors all communication and interaction on a device. Keyloggers are an example
TrojanAppears legitimate but steals data, spies or crashes the computer
AdwarePeppers user with unwanted adverts to get them to spend money
ScarewareTakes user to a page to buy a fake security program
BotnetInfected devices used to spread malware across a network
Theft of Data
PhishingFraudulent emails/websites to trick users into revealing personal information. Spear phishing = targeted. Smishing = via SMS
PharmingCreates fake websites OR alters DNS servers to redirect traffic to fake sites even when correct URL typed
Protection Methods
Anti-virusChecks downloads against virus definitions. Quarantines matches. Must be updated regularly
CAPTCHAIdentifies whether user is human or bot. reCAPTCHA uses extracts from books
HTTPSKeeps communications private. Uses SSL and TLS encryption
Passwords8+ characters, mix of letters/numbers/symbols, upper and lower case, changed frequently, not guessable
Backup Types
TypeWhat is copied
FullALL files every time
DifferentialFiles changed since last FULL backup
IncrementalFiles changed since last backup of ANY type

▾

Digital FootprintAll data a user creates online which is recorded and stored

Ch 8Implications of Digital Technologies
▾
Data Protection
Companies must: use data fairly/lawfully, for limited stated purposes, not keep it longer than necessary, handle it securely.

Individuals have the right to: access their data, have inaccurate data rectified, claim compensation, object to processing.
Health & Safety Issues
IssueCauseSolution
Eye StrainBlue light from screensRegular breaks, blue light filter
RSI / Wrist PainPoor posture, incorrect useErgonomic devices
Back/Neck AchePoor postureCorrect posture
Trip HazardsTrailing wiresGood cable management
Sustainability Issues
Power useICT uses non-renewable energy. Solution: renewable energy, efficient devices
Cooling systemsData centres use huge amounts of power. Solution: build in cold environments
E-wastePoisonous substances (bromine, mercury, chlorine) leak when disposed irresponsibly. Solution: recycling, legislation
