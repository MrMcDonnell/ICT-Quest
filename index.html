Ch 1Types of Digital Devices
▾
Key Devices
MainframeLarge powerful computer that carries out complex tasks (e.g. statistical analysis) rapidly and can be used by many people simultaneously
MicroprocessorControls what a computer does - takes data as input, processes it, gives an output. Found in washing machines, TVs, household appliances
Single Board ComputerAffordable computers used in education, embedded computing and physical computing
Embedded ComputingHardware fixed in position carrying out a specialist task (e.g. calculators). Opposite of physical computing
Physical ComputingInteractive systems that detect and respond to the surrounding environment (e.g. robotics)
SIM CardSubscriber Identity Module - identifies the device on the mobile phone network
SmartphoneMobile phone with Wi-Fi, internet access, features of cameras and game consoles. More complex OS uses more energy so requires more frequent charging
TabletSlightly bigger than smartphones, carries out mostly the same functions
ConvergenceWhen the designs of devices change so they become similar to another (e.g. laptops that flip into tablets)
GPSGlobal Positioning System - multiple satellites cross radio signals to pinpoint location. Does NOT need internet
GISGeographical Information System - renders maps, roads, houses. DOES require internet
Other Digital Devices
DevicePurposeKey detail
CameraStill photosQuality depends on lens, image processor, sensor resolution
Game ConsolePlay video games on TVMotion/wireless/VR controllers. Handheld = less storage, lower quality games
Smart TVTelevision with internet appsQuality depends on resolution (HD/UHD). Manufacturers show vertical pixels only
PVRPersonal Video RecorderRecords broadcasted content to watch later
Set-top boxSends video/audio from broadcaster to TVRequired for digital TV signals
Media PlayerPresents audio/video on TVe.g. Apple TV, Google Chromecast. Content from internet or local network
Device Features
PortabilityEasy to carry and move around
PerformanceHigh speed = can process information quickly. Requires good processor and large RAM. Otherwise virtual memory is used (much slower)
StorageMore storage = more files and programs can be stored. Also affects performance via virtual memory
User InterfaceThe method by which the user interacts with the system (CLI, GUI, Menu-driven, Voice, Gesture)
ConnectivityDevices can share data wirelessly or via a wire
Media SupportItems such as memory cards can be read and written. Some devices need external devices for this
Energy ConsumptionLow energy = longer battery life = saves money + shows social responsibility
Expansion CapabilitySome PCs allow additional components through expansion slots
Security FeaturesSoftware: PIN/password, swipe patterns, biometrics. Physical: specialist slots/locks
User Interfaces
CLICommand Line Interface - typed commands. Complicated and inefficient
Menu-DrivenChoosing from a list menu (e.g. ATMs). May not give user exactly what they want
GUIGraphical User Interface - windows, icons, menus. Very effective but requires high storage
Voice-DrivenBy speaking e.g. Siri
Gesture InterfaceSwipes/finger movements. Suitable for people with low mobility
Accessibility Devices
Braille KeyboardFor people with visual impairment
Gesture InterfaceFor people with low mobility

Ch 1Storage
▾
Storage medium = what holds the data (e.g. DVD disc). Storage device = what reads it (e.g. DVD drive). Secondary storage is non-volatile - data is not lost when power is lost.
Hard Disk Structure
ComponentsMade up of a spindle, concentric platters, and a read/write head
Speed factors(a) Speed of concentric platters (RPM) (b) How fast the read/write head moves
ReadingRead/write head changes magnetic field to electric current
WritingRead/write head changes electric current to magnetic field
Seek TimeTime taken by the RW head to locate the area on the platter where it needs to read/write data
Optical Media
MediaCapacityMethod
CD700 MBLaser writes on plastic below layers of aluminium and acrylic
DVD4.5 GB (1-sided) / 18 GB (2-sided)Shorter wavelength red laser
Blu-Ray25 GB (1-sided) / 50 GB (2-sided)Even shorter violet laser. Has scratch protection
All can be Recordable (R). CD and DVD can be Writable (W). DVD can be written, erased and written again (RE). DVD cannot play Blu-Ray but Blu-Ray can play DVD.
How storage media store binary data
Hard DiskChanges the magnetic charge on the platter to positive/negative to represent 0 or 1
Optical MediaTiny bumps on surface. Laser shines on spinning surface. Reflected light = 1, scattered light = 0
Flash MediaDifferent levels of charge in tiny individual cells to represent 0 or 1. No moving parts
Magnetic TapeChanges the charge on tape to positive/negative. Originally for music, now used for both
Data Calculations
8 bits = 1 byte | A nibble = 4 bits
1 KiB = 1024 bytes (2¹⁰) | 1 GiB = 1024³ bytes
GB = 1,000³ (decimal). GiB = 1024³ (binary - how computers measure)
Example: bits in 128 GiB = 128 × 8 × 1024³

Ch 3Memory & Processors
▾
Memory is accessed faster than secondary storage. It stores instructions so the processor can quickly fetch, decode and execute them.
Types of Memory
RAMVolatile - data lost when power is lost. Stores programs currently in use. Bigger RAM = more files open without needing virtual memory
Virtual MemoryCreated when RAM is full. Secondary storage used instead. Processor fetches from secondary storage which is much slower - massively impacts performance
ROMNon-volatile - data kept when power is lost. Stores boot data on PCs or data for single-use computers (calculators, digital watches). Cannot normally be changed
PROMProgrammable ROM - data can be written once only
EPROMErasable Programmable ROM - erased and rewritten using UV light
EEPROMElectrically Erasable Programmable ROM - erased by applying high voltage to a pin. Developed into flash memory
Flash MemoryA type of EEPROM. No moving parts - portable and low power consumption. Used in SSDs and SD cards
Processors
Processor CycleThe cycle by which a processor fetches from memory, decodes and executes instructions
Clock SpeedNumber of times per second a processor can carry out one or more instructions. Measured in Hertz (Hz)
Multi-coreMore than one CPU in a processor. A quad-core has 4 CPUs. More cores = more instructions processed simultaneously
Ch 4Digital Communications
▾
Speed & Volume of Data Transfer
BandwidthAmount of data transferred per second. High bandwidth = rapid uploads/downloads, complex tasks happen quicker
LatencyTime it takes data to travel between two devices. Low latency = no lag, no delay in live events
BufferArea of storage used to temporarily store data when streaming. If buffer empties, video pauses until it refills
Data transfer also affected by: method of transfer (wired/wireless), interference, blockages, and distance
Network Types
LANLocal Area Network - small geographical area (e.g. school)
WANWide Area Network - larger area than LAN. Internet is the largest WAN. WANs connect LANs to each other. Slower than LAN
PANPersonal Area Network - group of devices near one individual. WPAN = fully wireless version
TetheringHost device shares its mobile broadband (4G/5G) with another device. Bandwidth shared equally - both experience slowdowns
Methods of Communication
MethodSignal typeUses
SatelliteRadio wavesGPS, TV (DVB-S), Telephone (remote), Military
BroadcastRadio wavesTelevision, Radio shows
WiredElectrical signalsNetworking, Peripherals
WirelessRadio wavesNetworking, Peripherals
Satellite Communication
How it worksSignals sent from device to satellite. Satellite sends them to the receiving device via antenna
AdvantagesNot affected by power shortages. Accessible all the time
DisadvantagesAffected by weather and atmospheric conditions. Cannot go through solid objects - not efficient in cities with tall buildings
Wired Communication Types
ConnectionPurpose
HDMIDigital video connections
S/PDIFDigital audio connections
MinijackPersonal headphones
USBStorage transfer
EthernetNetworking - a standard for computer communication
Wireless Communication Types
Wi-FiBluetooth3G / 4GInfraredNFC
Wired vs Wireless
Wired advantagesWireless advantages
FasterLower cost (no cables needed)
More stableLess maintenance
No tripping hazard, less mess, more portable
Ch 5Networks
▾
Device Identification
IP AddressNOT fixed - changes with network. Assigned by DHCP. IPv4 = 8 numbers separated by dots. IPv6 = 8 groups of 4 hexadecimal characters separated by colons. IPv6 developed because devices grew faster than available IPv4 addresses
MAC AddressFixed - unique to device and its NIC. 6 pairs. First 3 pairs = manufacturer. Last 3 pairs = specific device. Used to identify/track devices and manage access rights
HexadecimalBase-16 number system using digits 0 - 9 and letters A - F
Network Components
RouterStores all connected devices' IP addresses. Forwards network traffic on the fastest route
SwitchHas many ports to connect devices with cables
GatewayConnects LANs to WANs. Firewalls are found here
WAPWireless Access Point - connects Wi-Fi devices to a wired network wirelessly. Often built into routers
BoosterAmplifies network signal to cover larger distances
ServerShares resources with connected devices (clients). Types: Authentication, Application, File, Print, Web
Connecting to the Internet
ISPInternet Service Provider - guarantees access to the telecommunications infrastructure
Web BrowserTakes requests and guarantees access to web servers
Search EngineUser enters keywords compared against a database of web pages. Returns most relevant results
Filter SoftwareAdministrators control access to content by URL. Whitelist = allowed. Blacklist = denied. None = automatically whitelisted
LAN Types & Benefits
Peer-to-peerDevices share resources directly - no server
Client-serverAll devices (clients) connect to one central server
Benefits of any LAN: shared files/storage, shared peripherals, easier communication, flexibility, better media usage, shared internet

Extra benefits of client-server: roaming profiles, centralised backup, admin control over access rights, shared applications
Securing Data on a Network
FirewallFound on gateways. Controls what can enter/leave the network
Caesar CipherShifts all data by a fixed number. Very easy to crack - weakest encryption
Symmetric KeySame key used to encrypt and decrypt. Both parties must share this key
Public KeyPublic key encrypts. Private key (recipient only) decrypts. Most secure
WEPWireless Encryption Protocol - all data encrypted with same key. Easy for eavesdroppers to crack
WPAWi-Fi Protected Access - updated WEP. Every device AND every data packet gets a unique key
VPNVirtual Private Network - encrypted tunnel for secure remote access to a LAN. Uses: secure payments, avoid surveillance, access work network from home, access geo-locked content
Transaction LogsTrack all data exchanges on the network
File Access PermissionsControl which users can access which files
Online Payments
Card details required: Card Number, Card Security Code (CSC), Expiry Date, Cardholder Name
Third-party processors: PayPal, BenefitPay
Contactless payment uses NFC and RFID - less secure as no PIN required
Ch 6Risks to Data & Information
▾
Unauthorised Access
Cybercriminals gain access by guessing logins or using computers/AI that try ~1000 logins per second. They target the weakest, most vulnerable devices to install botnets which then infect the rest of the network.
Malware Types
VirusNormally attached to an email. Spreads between files
RansomwareEncrypts files and demands a ransom to return the data
SpywareMonitors all forms of communication and interaction on a device. Keyloggers are an example
TrojanAppears legitimate but is actually stealing data, spying, or crashing the computer
AdwarePeppers the user with unwanted adverts to get them to part with money
ScarewareTakes the user to a page to purchase a fake security program
BotnetInfected devices used to spread malware. Installed on weakest devices - once infected they infect the rest of the network
Theft of Data
PhishingSending emails or creating websites to trick someone into giving personal information. Spear phishing = targeted at small group. Smishing = via SMS
PharmingCreates fake websites OR alters domain name servers to redirect traffic to fake sites even when correct URL is typed. Also done via misspelled URLs
Protection Methods
Anti-malware / Anti-virusConstantly checks files being downloaded against virus definitions. Matches are quarantined. Must be updated regularly
CAPTCHAIdentifies whether user is human or computer. May use text, images or puzzles. reCAPTCHA uses extracts from books - typed data helps digitise eBooks
HTTPSHypertext Transfer Protocol Secure. Keeps communications private. Uses SSL (Secure Socket Layer) and TLS (Transport Layer Security)
PasswordsMust be: more than 8 characters, mix of letters/numbers/symbols, upper and lowercase, changed frequently, not easily guessable (e.g. not a birthday)
Backup Types
TypeWhat is copied
Full BackupALL files - every time
Differential BackupFiles changed since the last FULL backup only
Incremental BackupFiles changed since the last previous backup (any type)
Best backup practice: schedule and automate, run during low activity times, store in multiple locations, use online storage, create more than one copy

Digital FootprintAll data a user creates online which is recorded and stored. Think carefully before posting - it can be accessed by anyone and easily shared
Impact of Less-Restricted Access to Networks on Society
Media & RepresentationImproved - people freely voice their own opinions
User-Generated Reference SitesRisen (e.g. Wikipedia) - making truth and accuracy less reliable, limited experts/editors
Monitoring of Social NetworksAdjusted - people can easily organise riots and strikes
Police & ModerationImproved through CCTV - helps reduce crime rates
Positive MovementsPeople gather for causes such as the Digital Humanitarian Movement
Ch 8Online Communities
▾
An online community is a group of people with a shared common interest who communicate online. Each has: a target audience, a function (what it does), and features (how it does it)
7 Types of Online Community
Social NetworkingAllows members to socialise and connect through shared interests. Features: profiles, share/comment/follow, status updates, tags, groups, reactions, notifications, third-party integrations, analytics
Online GamingMembers play multiplayer games together. Features: user profiles, game info/manuals, experience points, discussion boards, online/inactive statuses
Online WorkspaceMembers collaborate for work. Features: cloud storage, chat rooms, editing permissions, comments, virtual meeting platforms, shared calendars
VLE (Virtual Learning Environment)Teachers and students access learning/assessment materials. Features: log-in systems, gradebooks, feed/timeline, submit assignments, MCQ quizzes with auto-grading, share audio/video/links
WikiWebsite prepared by several users who can all add/edit content (e.g. Wikipedia). Features: member accounts, edit buttons, structured language, search tools
ForumMembers come together for structured discussions. Features: groups, moderators, administrators, posts & threads, ratings, private messages
Social BookmarkingUses tags to categorise web documents/URLs so others can find content via tag searches. Features: social networking features, third-party integration, tags, user accounts
Social Networking - Targeted Marketing
1. Social networks store user data in databases and analyse it → 2. Sold to advertisers → 3. Advertisers target relevant sponsored posts based on age, gender, browsing history

Analytics = information from data analysis. Used to find most effective communication methods
Third-party integrations = links to social networks so people can easily share content
Forum Roles & Safety Features
ModeratorCan allow or block posts and members
AdministratorSame as moderator PLUS can promote members to moderators or demote moderators back to members
ThreadA series of messages concerning the same subject
Word/URL CensoringPosts scanned for inappropriate content. Rejected or sent to moderators if found
Ignore/BlockMembers can be muted or stopped from accessing the forum
Report/FlagAllows members to alert moderators about rule-breaking
Online Safety in Communities
AnonymityCan protect users but also allows people to misrepresent themselves. Report any signs immediately
GeotaggingLocation data embedded in photos. Can reveal where user lives or spends time. Always deactivate this feature. Check privacy settings regularly
CyberbullyingReport at any time, whether victim or witness

Copyright Legislation
Copyright gives the creator of an original work sole authority to use and distribute it. Buying content (e.g. an eBook) gives the right to access it but NOT to copy or distribute it. Creating and sharing copies without permission is illegal. Some content is exempt from copyright.

Ch 10Online Information
▾
Primary SourceYou own the data (e.g. photos you have taken, articles you have written)
Secondary SourceSomeone else owns the data and you are using it (e.g. radio programme, TV, books)
Evaluating Online Information - it must be:
Accurate (not incomplete or false)Not too old or too newRelevant to topicReliable (matches other sources)Not biased (both sides)
To check for bias: examine statistics used, ask questions about opposing arguments, check reliability and look for missing information
Search Engine Tips
+ (AND)Adds a required term to the search
- (NOT)Excludes a word from search results
"phrase"Matches the exact phrase in quotation marks
Copyright & Plagiarism
Always be aware of copyright on data you use. To avoid plagiarism: credit the source and state it is not yours, rephrase in your own words, or include URL, author's name and publication date

ServiceKey details

Impact on Organisations
Improved communicationAccess to global marketsAccess to global workforceUse of big dataChanged security needsIncreased competition
Transactional Data & Cookies
Transactional DataData sent between devices. Usually stored in cookies. Can include: time/date of transaction, IP address, referring website, products bought/viewed, basket items, buttons pressed, form data entered
Session CookieOnly stored until a webpage is closed
Persistent CookieRecords information about internet use over time. Used to keep a user logged in. Allows advertisers to track data
Third Party CookiePersonalises user experience through targeted marketing. Used on pages with banner advertisements. Ad server can store a cookie on user's device when they visit such a page
Targeted Marketing
